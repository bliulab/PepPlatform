# Web 与 CLI 分类训练损失

Web 入口位于新建实验第 3 步 **Predictor and training → Custom → Classification loss (optional)**，默认折叠。
它与语义相似度辅助损失分别配置。

| 训练路线 | 可选损失 | 未指定或沿用默认时 |
| --- | --- | --- |
| 通用单序列神经网络，包括预训练残基特征接序列骨干 | BCE、WBCE、ASL | BCE |
| ESM2、ProtBert、ProtT5、ESMC/ESM3 池化特征接 MLP | BCE、WBCE、ASL | WBCE，权重上限 20 |
| PPI、HLA-I、HLA-II 神经网络 | BCE、WBCE | WBCE，权重上限 50 |

纯传统分类器与已训练模型的集成不提供损失选择。导出嵌入的两阶段路线中，损失选择作用于第一阶段的神经网络分类训练，不改变下游传统分类器的目标函数。TPpred-SC 的对比预训练阶段保持原样，所选分类损失用于其分类微调阶段。

## CLI 对应参数

单序列任务保持原有参数值：`--multilabel_loss bce`、`balanced_bce`、`asymmetric_focal`，分别对应 BCE、WBCE、ASL；`auto` 按上表保留路线默认值。

- WBCE：`--multilabel_pos_weight_cap`，默认 20，必须为有限数且 ≥ 1。权重仅使用训练标签计算，公式和最小权重 1 保持不变。
- ASL：`--asl_gamma_pos` 默认 1，`--asl_gamma_neg` 默认 4，均须为有限非负数；`--asl_clip` 默认 0.05，须在 `[0, 1)` 内。
- 配对任务：`--loss_type bce|wbce`；`--pos_weight_max` 默认 50，必须为有限数且 ≥ 1。配对任务本次不增加 ASL。

Web 沿用既有实验配置接口，只保存显式设置的损失参数。旧实验缺少这些字段时不自动补入；克隆配置保留显式值和字段缺省的区别。新模型元数据分别保存请求的损失、实际解析的损失、参数以及语义辅助契约。

## 历史复现与版本

本次新增池化 MLP 的显式选择能力，保留其 `auto` 的历史 WBCE 默认值；通用序列的 `auto` 仍为 BCE，配对默认仍为 WBCE。没有更改损失公式、语义采样、语义损失、数据划分、阈值选择和指标。

训练脚本发生了扩展，源码哈希会变化。历史精确复现继续以原实验冻结的源码、配置、数据、缓存、权重、种子及环境为准；不以当前工作区脚本覆盖历史快照。旧版池化路线曾忽略显式损失参数，使用新代码显式选择 BCE／ASL 或调整权重上限会产生新的实验，不能将其冒充原实验复现。

现有模型和运行记录不会被改写。新配置应保存为新的运行，并按对应的源码版本、配置和环境复现。
